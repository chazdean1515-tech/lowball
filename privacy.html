Privacy

Effective October 5, 2026.

Lowball is a static website. Search and the state tabs run in your browser. The pages do not ask you to create an account, and they do not include analytics or advertising scripts.

These pages do not set cookies.

The site is hosted on GitHub Pages. GitHub may keep server logs, such as an IP address, the browser type, and the page requested. Lowball does not operate that host and does not control those logs. GitHub describes what it collects in the GitHub Privacy Statement.

Links on a listing go to Redfin or Zillow. Those sites have their own privacy practices.

To reach Lowball, email contact@uselowball.com. Do not send account numbers, passwords, or other sensitive information in that email.

Lowball is not affiliated with Redfin, Zillow, or any MLS. The boards are not a live feed.
